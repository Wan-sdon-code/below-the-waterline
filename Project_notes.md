# 📝 Python Script Notes

- `print()` → Shows words on the screen.
- Variables → Save the job information.
- `improvement` → Works out the change from before to after.
- `if` → Checks if the change is big.
- `elif` → Checks if there is some change.
- `else` → Shows a small change.
- `questions` → Saves a list of questions.
- `for` → Shows each question one by one.

## 💡 What the Script Does

The program uses a made-up ship cleaning record.

It shows:

**Vessel → Marine growth → Cleaning time → Before & after condition**

It calculates the change:

**9 - 4 = 5 points**

So the result is:

**🟢 BIG CHANGE**

Then it gives questions that could be checked when there are more job records.

The idea is simple:

> **One job gives one record. Many jobs can start showing a pattern.**
